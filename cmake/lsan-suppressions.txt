# LeakSanitizer suppressions for the score test suite.
#
# Matched against the leak's allocation stack: `leak:` takes a substring of a
# function name, a source file, or a module. Entries name third-party code
# only: a score allocation site never belongs here.
#
# Nothing belongs here that hides a defect a test run could fix. One entry, one
# justified family, one comment saying why it is here and what it would take to
# remove it.
#
# ---------------------------------------------------------------------------
# libossia's websocket_server::stop() deliberately leaks a shared_ptr copy of
# the websocketpp endpoint (workaround for websocketpp handler lifetime bugs).
# LSan matches the allocation stack, so these name the leaked copy (stop) and
# the members that allocate what it keeps alive. Remove once libossia is off
# websocketpp.
leak:ossia::net::websocket_server::stop
leak:ossia::net::websocket_server::websocket_server
leak:ossia::net::websocket_server::listen
leak:ossia::net::websocket_server::start_accept

# ---------------------------------------------------------------------------
# Third-party libraries that keep allocations for the life of the process.
#
# Khronos Vulkan validation layer internal state; alsa-lib's global config
# cache and pcm plug-in modules. Not score's allocations, do not grow per test.
# The alsa config cache is matched by its filler function, not libasound.so, so
# score leaks passing through alsa callbacks stay visible.
leak:libVkLayer_khronos_validation.so
leak:snd_config_update_r
leak:libasound_module_
