# LeakSanitizer suppressions for the score test suite.
#
# Matched against the leak's allocation stack: `leak:` takes a substring of a
# function name, a source file, or a module. Every entry here is anchored on a
# score symbol so it cannot silently widen to third-party code.
#
# Nothing belongs here that hides a defect a test run could fix. One entry, one
# justified family, one comment saying why it is here and what it would take to
# remove it.
#
# ---------------------------------------------------------------------------
# The makeGUIElements family (sanitizer ledger T6).
#
# Parent-less QToolBar / QAction / widget instances are created per
# application-plugin instance, handed to score::GUIElements, and never freed.
# In a shipped ossia-score that is one leak set at exit: the process builds a
# single application and then terminates, so nothing accumulates. In the test
# suite every Catch2 case constructs its own MinimalGUIApplication, so the
# same leak multiplies once per case.
#
# That makes it the dominant noise source, and what makes every GUI test's
# LSan report unreadable, since a real leak elsewhere is invisible underneath
# it.
#
# It is suppressed to make the other leaks legible, not because it is
# acceptable. It is a genuine ownership bug: these widgets want a parent, or
# GUIElements wants to own them. Fixing it removes these lines.
