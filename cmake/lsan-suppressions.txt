# The makeGUIElements family (sanitizer ledger T6).
#
# Parent-less QToolBar / QAction / widget instances are created per
# application-plugin instance, handed to score::GUIElements, and never freed.
# In a shipped ossia-score that is ONE leak set at exit: the process builds a
# single application and then terminates, so nothing accumulates. In the test
# suite every Catch2 case constructs its own MinimalGUIApplication -- roughly
# 73 constructions per binary -- so the same leak multiplies into about 400
# blocks per test.
#
# Measured in the 4f526348fc sanitizer run: 9.51 MB of the 11.32 MB leaked,
# 84% of the total, across 31 of the 58 leak-only tests. It is the dominant
# noise source, and it is what makes every GUI test's LSan report unreadable --
# a real leak elsewhere is invisible underneath it.
#
# So this is suppressed to make the OTHER leaks legible, not because it is
# acceptable. It is a genuine ownership bug: these widgets want a parent, or
# GUIElements wants to own them. Fixing it removes these lines. Until then, a
# suppressed known leak beats an unreadable report -- but do not read these
# entries as "not a bug".
